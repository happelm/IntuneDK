# Lab 10.1 – Spot the difference

**Estimated time:** 30 minutes

> **New:** The log sets for this lab are not in the Labfiles yet. The trainer provides them in class.

**Goal:** Compare a known-good and a broken log set and name the layer and the cause.

1. Open the known-good and the broken log set in CMTrace.
2. Start with `IntuneManagementExtension.log`, then follow the component it names.
3. Find the first line where the broken set differs from the known-good set.
4. Name the layer and the likely cause.
5. Compare your result with your neighbor, then with the trainer.

### Checkpoint

- [ ] First deviation found
- [ ] Layer named
- [ ] Cause matches the solution

**Why:** This is the method of the whole course: know what healthy looks like, then find the first deviation.
